# YouTube動画 スクリーンショット撮影プロンプト

対象URL: https://youtu.be/JFFL7bq18QQ?si=RM-3soCDW_VYDVNB

文字起こしと映像を同期し、3D操作・設定・生成結果・失敗・修正が確認できる代表フレームを保存する。

1. 構造化文字起こしを読み、設定/インストール/MCP/プロンプト/生成/モデル/Blender/リグ/アニメーション/エラー/修正/完成の周辺を候補化。
2. 候補時刻の前後数秒も比較し、UI/モデルが明瞭なフレームを選択。
3. 連続重複を削除し、操作前後比較だけ必要に応じ2枚残す。
4. `HH-MM-SS_event_slug.jpg` で保存し、`SCREENSHOT_INDEX.json` に timestamp/reason/transcript_excerpt/filename を残す。
5. 代表画像を最大12枚程度へ絞り、`CONTACT_SHEET.jpg` を生成。
6. 黒画・単色画・破損画像は再撮影。360pしか取れなくても停止せず品質を記録。
7. 元動画フレームを保存し、画像生成で代替しない。
8. エラーは `ERROR_REPORT.json` へ追記して残りを続行。

優先場面: AI/MCP設定、最初の自然言語プロンプト、最初の3D結果、大変更前後、リグ/アニメーション前後、失敗状態、AI修正直後、最終結果。
